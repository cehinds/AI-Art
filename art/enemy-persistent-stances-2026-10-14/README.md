# Persistent enemy stance source package

This source package adds one persistent counter pose for each canonical enemy, plus three held-pose repairs that the reviewed catalog could not select from the original action frames. Source masters are transparent 512×512 PNGs in `source-overrides/<enemyId>/<pose>.png`; runtime files are written additively to `hd/assets/enemy-poses/expansion/<enemyId>/<pose>.webp`.

Build high exports from the reviewed PNG masters with `node build-stance-assets.cjs`. The script uses libwebp `cwebp -m 6 -q 90 -alpha_q 100 -alpha_filter best`. Generate light twins through the normal `node tools/mobile-art.mjs` workflow, then refresh `node tools/manifest.mjs --write`. Source-overrides, catalog, and provenance stay in Git. Embedded editable Sprite Workshop projects and visual contacts are delivered in the local D: output package and are reproducible from their builder.

All 36 additions have coordinator visual approval; owner art acceptance remains pending. `generation-provenance.json` records each source, runtime high/light hash, alpha bounds, and encoder settings. `existing-family-selection.json` records the per-enemy choices for all six held stance families, including the 33 new counters. The 33 editable six-family Sprite Workshop projects and contact sheets are delivered under `D:/repos/.codex/outputs/enemy-persistent-stances-20261014/authoring`. A hash receipt at `D:/repos/.codex/outputs/enemy-stance-repair-2026-10-14/original-792x2-hash-proof.json` verifies the prior 792 high and 792 light runtime pose assets are unchanged.
