# World builder reference study

Researched 2026-10-24 for the user's request for 100 more biome tiles, boats, planes, trees, mountains and cavern entrances. Online references are kept outside Unity Assets. New generated art retains the approved project style; reference images are not production exports.

| Reference | Inspected evidence | Use |
| --- | --- | --- |
| [FFII Pixel Remaster screenshot gallery](https://www.rpgfan.com/gallery/final-fantasy-ii-pixel-remaster-screenshots/) | `ffii-overworld-reference.jpg`, image 003: overhead airship, clustered dark conifers, yellow-green plains, blue sea and pale coast edge. Visually inspected. | Terrain color hierarchy, tree clusters and recognizable world-map vehicle silhouettes. The screenshot uses a tilted map presentation; new tiles retain the project's orthogonal view. |
| [Original FFII vehicle sprites](https://www.videogamesprites.net/FinalFantasy2/Objects/Vehicles.html) | Downloaded front ship and airship GIFs; viewed their first frames enlarged with nearest-neighbor sampling in the two `*-inspection.png` files. The ship shows a central mast, broad white sail and warm hull; the airship shows a narrow body and paired lateral shapes. | Original-game silhouette reference, not a high-resolution texture or animation timing source. |
| [FFII Pixel Remaster vehicles archive](https://www.spriters-resource.com/pc_computer/finalfantasy2pixelremaster/asset/606657/) | Read page metadata; direct PNG download returned a browser challenge. No local PNG was obtained or used. | Discovery only. |

The approved project transport source (`ArtSource/Campaign/world/transport-canoe-ship-airship-chocobo-4x4.png`) establishes the existing wooden hull, cream sail/envelope, blue/red trim and gold fittings. `Review/art/03-environment-kit.png` establishes the clustered pixel shading. Both were visually inspected before new generation. The requested propeller plane is an optional original extension in this palette; it is not presented as an original FFII vehicle.

Terrain-specific research and inspected images are recorded separately in the natural/extreme biome source ledgers. The ten biome families are a practical construction set, not an exhaustive claim about all possible biomes or all original maps.
