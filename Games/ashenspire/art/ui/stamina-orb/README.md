# Stamina orb and mana harness

Approved by the owner on October 3, 2026 for AshenSpire's combat footer.

The five PNG files are the original transparent masters generated using OpenAI's built-in imagegen tool. `prompts.json` records the generation prompts. The design follows the owner's approved weathered circular metal harness, emerald stamina orb, green action sigil, and sapphire available/spent mana diamonds. No third-party artwork was imported.

`approved-layout.json` is the owner's final SP Atelier layout: hidden sigil, independently sized/positioned SP number and label, available mana diamonds at 130% and spent diamonds at 60%. Resource values are illustrative; the game supplies current SP/MP and maximums live.

`hd/assets/ui/stamina-orb/*.webp` contains alpha-trimmed runtime images, scaled proportionally to 512px high, encoded with Sharp WebP quality 90 / alpha quality 100 / effort 6. Alpha bounds use the first/last pixel above alpha 20, matching the editor's placement. `export-receipt.json` records each crop and dimensions. Source masters remain intact. The smaller twins and their provenance are generated by `node tools/mobile-art.mjs`; the release manifest is generated by `node tools/manifest.mjs --write`.

Stamina text is drawn live, not baked into any image. The ring begins at 12 o'clock and proceeds counterclockwise, with one gem per maximum MP. The mana count changes spacing, while the approved layout supplies radius, component sizes and text positions.
