# Illustrated card components

Owner-approved Card Studio exports from the AshenedSpire JavaScript prototype, including the corrected Gorefire layout and centered mana value. Original PNGs are retained here for editing; runtime WebP exports are lossless with unchanged dimensions and alpha, so JSON crop coordinates remain exact. The game composes text and live costs separately.

These are first-party AI illustrations produced with OpenAI image generation and refined through the project Card Studio. No third-party asset licence is claimed. Source: https://github.com/cehinds/ashenedSpire-js (approved build 811, commit a499c509). Export hashes and encoder settings are in export-receipt.json.
